# winget manifest

Source of truth for the `Talessai.Satsuma` package in the
[Windows Package Manager community repository](https://github.com/microsoft/winget-pkgs).
The folder layout mirrors winget-pkgs (`manifests/t/Talessai/Satsuma/<version>/`), so a
version folder can be copied into a winget-pkgs fork as-is.

Users install with:

```powershell
winget install Talessai.Satsuma
```

See [RELEASING.md](../../RELEASING.md) for how to publish a new version.
